# Learn AI engineering by building the parts people usually skip.

AI is easier to understand when you can see the system, run the smallest version, make it fail, and explain what changed. This is a public learning path for developers, DevOps engineers, and platform professionals moving into AI.

## The point of view

This site is organized around a repeatable loop:

<div class="model-grid">
<div class="model-step"><span>01</span><strong>Unlearn</strong><p>Find the assumption that makes the topic confusing.</p></div>
<div class="model-step"><span>02</span><strong>Understand</strong><p>Build a clear mental model with the right vocabulary.</p></div>
<div class="model-step"><span>03</span><strong>Build</strong><p>Implement the smallest useful version in code.</p></div>
<div class="model-step"><span>04</span><strong>Break</strong><p>Test limits, failure modes, cost, and unsafe edges.</p></div>
<div class="model-step"><span>05</span><strong>Operate</strong><p>Make the system observable, secure, and maintainable.</p></div>
</div>

## Start with one honest lesson

The first sample lesson is about [context windows](foundations/context-windows.md). It begins with a common misconception, builds a mental model, implements a tiny experiment, and tests what happens when the context is too large, incomplete, or noisy.

The [learning model](learning-model.md) explains how to use the same structure for every topic. The [roadmap](roadmap.md) shows the full 48-week sequence and the portfolio milestones that make the learning visible.

## Public teaching, private planning

The GitHub repository is for lessons, labs, diagrams, examples, and carefully selected resources. The Excel workbook remains the private place for dates, hours, costs, progress, and personal notes. The public site does not need a second tracker.
