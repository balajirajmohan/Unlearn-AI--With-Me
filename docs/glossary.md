# Glossary

| Term | Plain-language meaning |
| --- | --- |
| Attention | A mechanism that lets a model weigh relationships between tokens while producing the next token. |
| Embedding | A numeric representation used to compare the meaning or features of items. |
| Context window | The bounded input and output space available to one model request. |
| RAG | Retrieval-augmented generation: select external evidence, then provide it to a model for an answer. |
| Reranking | A second retrieval step that scores a smaller candidate set more precisely. |
| Tool calling | A structured request from a model to an application-defined function. |
| Agent | A model-driven loop that selects actions, observes results, and continues within explicit limits. |
| MCP | A protocol for connecting model clients to servers that expose tools, resources, and prompts. |
| LoRA | A parameter-efficient adaptation method that trains small low-rank updates instead of all model weights. |
| KV cache | Stored attention key and value tensors reused during autoregressive inference. |
| TTFT | Time to first token. |
| TPOT | Time per output token after generation begins. |
| LLMOps | The practices for testing, evaluating, tracing, securing, and operating language-model systems. |
