# Curated learning path

The private workbook contains the full resource library. This page highlights a public backbone: first-party documentation, technically strong courses, and hands-on material that maps to the roadmap.

Paid resources are optional. Use the free or audit alternatives when they cover the same objective.

## How to choose

Use one backbone resource per phase, then add a first-party reference and one lab. Avoid collecting courses as a substitute for building. A resource earns a place here when it helps answer a concrete question or complete a reproducible experiment.
